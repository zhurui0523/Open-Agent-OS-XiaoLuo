## 产品决策覆盖

- 不创建开发文档中的 14 个具体 Skill；系统只提供 Package/Schema/Runtime 接入能力，具体 Skill 由项目方另行添加。
- 积分、额度和计费系统已经完整移除。
- 不提供“自定义接口编辑器”页面；第三方模型通过已支持的标准协议和 Provider Package 接入。
- 业务数据不使用浏览器本地存储；MySQL 与 OSS 是唯一事实来源。
- 第三方 API 只统计文本、图片和视频执行次数，不统计 Token、费用或第三方账单。

## 当前不能在本地伪装完成的外部阻塞

1. **旧数据正式迁移与黄金数据对照**：需要脱敏旧数据库样本、旧 OSS 对象清单和旧 Web 可运行基线。当前迁移框架、Dry Run/Verify 能力已具备，但没有这些输入不能声称迁移结果通过。
2. **多人实时协作**：在线光标、评论/提及和权限撤销后实时断连需要 WebSocket/CRDT 长连接服务及多客户端环境；当前已完成 P0 服务端保存与 revision 冲突处理。
3. **正式插件市场**：发布者身份、签名证书、审核、撤回与恶意包处置需要独立的信任和运营基础设施；当前 Package 生命周期和安装安全契约已经完成。
4. **CLI/Node/Python 隔离 Worker**：强隔离执行需要独立容器集群、资源配额和网络白名单，不允许在 Web/API 进程中用伪沙箱替代。
5. **托管平台后台定时触发**：代码已经提供受 Worker Token 保护的调度入口和自托管常驻 Worker；若托管平台不提供 Cron/Queue 绑定，关页后的持续轮询需要平台侧定时任务调用该入口。页面在线时仍有安全恢复路径。
