## 产品决策覆盖

- 不创建开发文档中的 14 个具体 Skill；系统只提供 Package/Schema/Runtime 接入能力，具体 Skill 由项目方另行添加。
- 积分、额度和计费系统已经完整移除。
- 不提供“自定义接口编辑器”页面；第三方模型通过已支持的标准协议和 Provider Package 接入。
- 业务数据不使用浏览器本地存储；MySQL 与 OSS 是唯一事实来源。
- 第三方 API 只统计文本、图片和视频执行次数，不统计 Token、费用或第三方账单。

## 仍需外部资源或真实输入才能完成的事项

1. **生产短信**：注册、改绑和找回密码流程已经完成；仍需阿里云短信 AccessKey、签名和模板编码，配置后就绪探针会自动转为健康。
2. **托管 Cron/Queue 触发器**：应用端受保护 tick、任务恢复和心跳已经完成；仍需托管平台或独立调度器按固定周期调用 `/api/v2/worker/tick`。
3. **隔离执行集群**：应用端协议、可信 Package 门禁和资源策略已经完成；仍需绑定真实容器/微虚机 Worker Endpoint 与 Token，不能在 Web 进程中伪造强隔离。
4. **旧数据正式迁移**：工具已经完成；仍需脱敏旧数据库连接、迁移映射、旧 OSS 对象清单与预期计数，才能执行生产迁移并签署黄金数据通过结论。
5. **外部发布者真实性证明**：站内管理员、公钥和 Package 签名链已经完成；如未来开放公共插件市场，还需线下/第三方主体认证流程，这不影响私有部署的签名与审核。
